## 📊 KPIs à suivre

Une fois lancé, suivez ces métriques:

1. **Trafic organique** (Google Analytics)
   - Visiteurs uniques/mois
   - Pages vues
   - Taux de rebond
   - Durée moyenne de session

2. **Positions SEO** (Search Console)
   - Position moyenne dans les résultats
   - Nombre d'impressions
   - Taux de clics (CTR)
   - Mots-clés performants

3. **Conversions**
   - Nombre d'images importées
   - Nombre d'exports PNG
   - Nombre d'exports PDF
   - Taux de retour

4. **Engagement**
   - Partages sociaux
   - Backlinks créés
   - Mentions sur le web
